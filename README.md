# 작은 전투

토이 배틀(코리아보드게임즈)에서 영감을 받아 8개 전장을 웹에서 둘이 즐길 수 있게 만든 비공식 MVP입니다.
이름만 입력하면 들어오고, 방을 만들어 초대 코드(또는 링크)를 보내면 친구가 들어옵니다.
두 명이 모이면 방장이 시작하고, 선공은 무작위입니다.

방을 만들 때 전장을 랜덤 또는 지정 맵으로 고를 수 있습니다. 방장은 시작 전 대기실에서 바꿀 수도 있습니다. 랜덤을 고르면 대전이나 재대전이 시작될 때마다 8개 중 하나를 다시 뽑습니다.

## 토이 배틀 전장

- 성채 평원 — 북 거점에서 다른 아군을 손으로 회수합니다.
- 열대 수영장 — 풀장 가장자리로 돌아가거나 섬을 밟고 가운데를 가로지릅니다. 숫자가 적힌 섬 거점에는 맞는 힘의 병정 또는 조커만 놓습니다.
- 구름 정원 — 가운데 하늘길이 곧게 뚫려 있어 빠르지만 막히기 쉽습니다. 구름 거점에서 병정 하나를 뽑습니다.
- 용암 정글 — 분화구를 네 용암 거점이 감싸고 오솔길이 촘촘합니다. 용암 거점에서 맞닿은 적 병정을 다른 인접 거점으로 밀어냅니다.
- 저주받은 묘지 — 위아래로 길게 도는 묘지 길과 예배당을 지나는 가운데 길이 있습니다. 묘지 거점에서 버린 내 병정을 손으로 되찾습니다.
- 카리브 해 — 섬과 암초로 이어진 바다입니다. 파랑은 북쪽·남쪽 항구 두 본부에서 연결을 시작하고, 빨강은 둘 중 한 본부만 점령해도 승리합니다.
- 우주정거장 메탈-X — 바깥 통로를 돌거나 금속 통로를 지나 중앙 코어로 들어갑니다. 금속 거점에서는 병정의 소환 능력이 발동하지 않습니다.
- 사막 참호 — 포탄 구덩이를 지나야 가운데 벙커에 닿습니다. 참호 거점에서 상대의 뒷면 손패 한 장을 골라 다음 차례에 배치하지 못하게 합니다.

원작의 전장 테마와 특수 효과를 참고했고, 온라인판의 거점 배치와 길은 대전용으로 재구성했습니다. 각 맵의 효과는 게임 방법에도 설명되어 있습니다.

## 실행

```bash
npm install
npm run dev        # 서버(3001) + 웹(5173) 함께 실행
```

브라우저에서 http://localhost:5173 을 열면 됩니다. 같은 브라우저의 탭 두 개로도 서로 다른 플레이어가 되어 테스트할 수 있습니다.
휴대폰에서 같은 와이파이로 접속하려면 `npm run dev`가 출력하는 Network 주소(예: `http://192.168.x.x:5173`)를 쓰면 됩니다.

배포용 빌드는 `npm run build` 뒤 `npm start`로 띄우면 3001 포트에서 정적 파일과 소켓을 함께 서빙합니다.

## 배포

서버 하나가 정적 파일과 소켓을 함께 서빙하므로, 프로세스가 계속 떠 있는 호스팅이면 어디든 됩니다. `render.yaml`이 들어 있어서 Render에서는 저장소를 연결하고 Blueprint로 만들면 끝입니다.

- 빌드: `npm ci && npm run build`
- 시작: `npm start` (`PORT` 환경 변수를 따르며, 기본 3001)
- 상태 확인: `/api/health`

방과 게임은 메모리에만 있어서 서버가 재시작되면 사라집니다. Render 무료 플랜은 15분 동안 접속이 없으면 잠들었다가 첫 접속 때 깨어나는 데 30초쯤 걸립니다.

## 검사

```bash
npm test           # 규칙 엔진 + 서버 테스트 (node:test)
npm run test:e2e   # 브라우저 두 개로 방 생성 → 입장 → 시작 → 첫 수 (Playwright, 데스크톱/모바일)
```

e2e는 처음 한 번 `npx playwright install chromium`이 필요합니다. `npm run dev`가 떠 있으면 그 서버를 그대로 씁니다.

## 구조

- `shared/` — 맵, 병정, 규칙 엔진. 서버와 클라이언트가 같은 코드를 씁니다.
- `server/` — Express + Socket.IO. 방·세션은 메모리에만 있어서 서버를 재시작하면 사라집니다.
- `src/` — React 화면. 게임판은 SVG이고, 휴대폰에서는 드래그·핀치로 움직입니다.
- `tests/` — 엔진/서버 단위 테스트와 `e2e/`의 브라우저 테스트.

## 확장 규칙 (지금은 꺼져 있음)

협공·보급소·확장 병정을 만들어 두었지만 아직 넣을지 정하지 않아 꺼 두었습니다. 서버를 `ENABLE_EXPANSION_RULES=1`로 띄우고 `src/App.tsx`의 `SHOW_RULE_OPTIONS`를 켜면 방을 만들 때 고를 수 있습니다.

- **협공** — 공격할 때 목표 거점과 길로 이어진 내 병정 수만큼 힘을 더합니다. 꽉스는 그대로 조커이고, 지키는 쪽은 보정이 없습니다.
- **보급소** — 위·아래 다리가 보급소입니다. 하나라도 차지한 채 차례를 시작하면 병정 1개를 더 받습니다(손패 8개 상한은 그대로).
- **확장 병정** — 그림자(2, 상대 본부 옆 거점에 연결 없이 배치), 공병(2, 맞닿은 길을 끊거나 다시 잇기, 본부 옆 길은 못 끊음), 기사(5, 내 병정 하나를 옆 빈 거점이나 내 거점으로 이동), 폭탄(1, 상대가 덮으면 그 병정이 터져 버려지고 폭탄은 남음, 꽉스만 해체)이 각 2개씩 들어옵니다. 끊긴 길은 배치와 본부 연결에만 영향을 주고, 영토 훈장 판정은 거점만 봅니다.

## 알아 둘 것

- 휴대폰에서는 게임판이 세로로 서고 내 본부가 아래쪽에 옵니다. 데스크톱은 가로가 기본이고, 게임판 오른쪽 아래 버튼으로 세로 보기와 오갈 수 있습니다. 선택은 그 기기에 기억됩니다.
- 한 차례에 생각할 시간은 50초입니다. 시간이 지나면 서버가 알아서 병정을 뽑거나, 뽑을 수 없으면 가장 약한 병정을 놓아 차례를 넘깁니다. 누군가 연결이 끊기면 시계도 같이 멈춥니다. 초 단위는 `shared/engine.ts`의 `TURN_SECONDS`에서 바꿉니다.
- 세션 토큰은 탭별(`sessionStorage`)로 보관합니다. 새로고침이나 잠깐의 연결 끊김은 같은 자리로 돌아오고, 탭을 닫으면 90초 뒤 자리가 비워집니다.
- 토이 배틀 전장별 특수 효과, 캡틴의 추가 배치, 영토 훈장 계산을 구현했습니다. 전장 배치는 온라인용 재구성이며 게임 화면의 '게임 방법'에 요약이 있습니다.
- 힘 5 `XB-42`는 상대 손의 무작위 병정을 버리지 않고 상대 병정 더미로 되돌립니다. 양쪽 화면에서 손→더미 복귀가 보이고, 북 거점·퇴각·증원으로 판이나 버림 더미의 병정이 손으로 돌아올 때도 별도 애니메이션이 재생됩니다.
